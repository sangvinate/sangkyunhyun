========================================
그래프 해설 문서 생성 가이드
========================================

1. 파일 구성
----------------
- 그래프해설.Rmd: R Markdown 소스 파일
- 워드문서_생성.R: Word 문서로 변환하는 스크립트
- humanoid_robot_forecast.R: 그래프 생성 스크립트

2. Word 문서 생성 방법
--------------------

방법 1: 워드문서_생성.R 스크립트 사용 (권장)
-------------------------------------------
1) R 또는 RStudio를 실행
2) 작업 디렉토리를 파일이 있는 폴더로 설정
   setwd("C:/Users/infomax/OneDrive/문서")  # 또는 해당 경로
3) 스크립트 실행:
   source("워드문서_생성.R")
4) 생성된 "그래프해설.docx" 파일을 확인

방법 2: 직접 명령어 입력
-----------------------
R 콘솔에서 다음 명령어 실행:

library(rmarkdown)
render("그래프해설.Rmd", output_format = "word_document")

방법 3: RStudio 사용 (가장 쉬움)
-------------------------------
1) RStudio에서 "그래프해설.Rmd" 파일 열기
2) 상단의 "Knit" 버튼 클릭
3) "Knit to Word" 선택
4) 자동으로 Word 문서 생성 및 열림

3. 필요한 패키지 설치
--------------------
처음 사용하는 경우 다음 패키지를 설치해야 합니다:

install.packages("rmarkdown")
install.packages("knitr")
install.packages("ggplot2")
install.packages("scales")

RStudio를 사용하는 경우 대부분 자동으로 설치되어 있습니다.

4. Pandoc 설치
--------------
R Markdown을 Word로 변환하려면 Pandoc이 필요합니다:

- RStudio 사용 시: 자동으로 포함되어 있음
- R만 사용 시: https://pandoc.org/installing.html 에서 다운로드

5. 문서 내용
------------
생성되는 Word 문서에는 다음 내용이 포함됩니다:

1) 개요
   - 골드만삭스 리서치 기반 분석 소개

2) 주요 데이터
   - 연도별 생산량 표
   - 전년 대비 증가량 및 증가율

3) 주요 분석 결과
   - 성장 추세 분석
   - 성장 단계별 구분 (초기/도입/급성장)
   - 산업 시사점

4) 시각화
   - 막대그래프 (원본 이미지와 동일한 스타일)

5) 연도별 상세 분석
   - 태동기 (2025-2027)
   - 시장 진입기 (2028-2030)
   - 성장 가속기 (2031-2033)
   - 대량 생산기 (2034-2035)

6) 결론 및 전망

6. 문서 수정하기
----------------
그래프해설.Rmd 파일을 텍스트 에디터로 열어서 내용을 수정할 수 있습니다:

- 제목 변경: title: "새로운 제목"
- 작성자 변경: author: "작성자명"
- 내용 추가/수정: Markdown 문법 사용
- 그래프 수정: R 코드 블록(```{r}) 내용 수정

7. HTML 문서로도 생성하기
-----------------------
Word 대신 HTML 문서로 생성하려면:

rmarkdown::render("그래프해설.Rmd", output_format = "html_document")

8. 문제 해결
------------

문제 1: "pandoc not found" 오류
해결: Pandoc을 설치하거나 RStudio를 사용하세요

문제 2: 한글 깨짐
해결: 파일 저장 시 UTF-8 인코딩 사용

문제 3: 패키지 오류
해결: install.packages() 명령으로 필요한 패키지 설치

문제 4: 그래프가 표시되지 않음
해결: ggplot2, scales 패키지 설치 확인

9. 참고 사항
------------
- Word 문서 생성 시 R Markdown의 그래프가 자동으로 포함됩니다
- 생성된 Word 문서는 추가로 편집 가능합니다
- 표와 그래프의 스타일은 Word에서 수정할 수 있습니다
- 원본 .Rmd 파일을 수정하면 언제든 재생성 가능합니다

10. 추가 기능
-------------
문서에 다음 요소들이 포함되어 있습니다:

- 표: 연도별 생산량 데이터
- 그래프: 막대그래프 시각화
- 통계: 자동 계산된 성장률과 총계
- 목차: HTML 버전에서 활성화 가능

문의사항이나 추가 수정이 필요하면 그래프해설.Rmd 파일을 수정하여
다시 렌더링하면 됩니다.
