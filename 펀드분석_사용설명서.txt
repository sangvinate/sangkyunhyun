펀드 성과 분석 R 프로그램 사용 설명서
========================================

1. 프로그램 개요
----------------
이 R 스크립트는 펀드의 보유내역과 매매내역을 분석하여 종목별 매매손익과 평가손익을 계산하고,
막대그래프로 시각화합니다.

2. 필요한 패키지 설치
--------------------
R 콘솔에서 다음 명령어를 실행하여 필요한 패키지를 설치하세요:

install.packages("dplyr")
install.packages("ggplot2")
install.packages("readr")
install.packages("tidyr")

파일명 예시 (실제 파일명에 맞게 스크립트 수정 필요):

4. CSV 파일 형식
----------------
각 CSV 파일은 다음과 같은 컬럼을 포함해야 합니다:

a) 보유내역 CSV (펀드보유내역_20251031.csv, 펀드보유내역_20251124.csv):
   - 종목명 : 종목 이름
   - 평가금액 : 해당 날짜의 평가금액
   - (추가 컬럼: 보유수량, 평가단가 등)

b) 매매내역 CSV (주식매매내역_20251101_20251124.csv):
   - 종목명 : 종목 이름
   - 매매구분 : "매수" 또는 "매도"
   - 수량 : 매매 수량
   - 금액 : 매매 금액
   - (추가 컬럼: 날짜, 단가 등)

5. 스크립트 수정이 필요한 부분
------------------------------
실제 CSV 파일의 컬럼명이 다를 경우, 스크립트에서 다음 부분을 수정하세요:

a) 파일명 (13-20 라인):
   nav_data <- read.csv("실제파일명.csv", fileEncoding = "UTF-8", stringsAsFactors = FALSE)
   holdings_1031 <- read.csv("실제파일명.csv", fileEncoding = "UTF-8", stringsAsFactors = FALSE)
   holdings_1124 <- read.csv("실제파일명.csv", fileEncoding = "UTF-8", stringsAsFactors = FALSE)
   trading_data <- read.csv("실제파일명.csv", fileEncoding = "UTF-8", stringsAsFactors = FALSE)

b) 컬럼명 (스크립트 전체):
   - 종목명, 매매구분, 수량, 금액, 평가금액 등
   - 실제 CSV 파일의 컬럼명으로 변경

8. 손익 계산 방식
-----------------
a) 매매손익 = 매도금액 - 매수금액

b) 평가손익 = (11/24 평가금액 - 10/31 평가금액) - 순매수금액
   * 순매수금액 = 매수금액 - 매도금액
   * 이는 순수한 가격 변동에 의한 손익만을 의미합니다.

c) 총손익 = 매매손익 + 평가손익

9. 문제 해결
------------
오류가 발생할 경우:

a) 파일 경로 확인:
   getwd()로 현재 작업 디렉토리 확인
   setwd("올바른경로") 로 변경

b) 파일명 확인:
   list.files()로 폴더 내 파일 확인
   스크립트의 파일명이 실제 파일명과 일치하는지 확인

c) 컬럼명 확인:
   데이터를 읽은 후 colnames(holdings_1031) 등으로 컬럼명 확인
   스크립트의 컬럼명을 실제 컬럼명으로 수정

d) 인코딩 문제:
   한글이 깨질 경우, fileEncoding 파라미터를 조정
   (예: "UTF-8", "CP949", "EUC-KR" 등)
