========================================
키움증권 보유내역 대시보드 사용 설명서
========================================

1. 프로그램 개요
----------------
이 R Shiny 앱은 키움증권 REST API를 이용해 계좌의 보유종목과 평가금액을
조회하여 웹 대시보드로 보여줍니다.

- 조회 전용입니다. 접근토큰 발급과 계좌평가잔고내역요청(kt00018)만 호출하며,
  주문/매매 관련 API는 일절 호출하지 않습니다.
- 화면 구성: 요약 카드(추정예탁자산/총매입/총평가/총평가손익/총수익률),
  보유종목 상세 표(CSV 저장 가능), 보유비중 그래프, 종목별 평가손익 그래프

2. 사전 준비 (키움 REST API 신청)
---------------------------------
a) 키움증권 홈페이지 > Open API > 키움 REST API 서비스 신청
b) https://openapi.kiwoom.com 에서 앱 등록 후 App Key와 Secret Key 발급
c) 모의투자로 테스트하려면 모의투자 신청 후 모의투자용 키를 별도 발급

3. 필요한 패키지 설치
--------------------
R 콘솔에서 다음 명령어를 실행하여 필요한 패키지를 설치하세요:

install.packages("shiny")
install.packages("httr")
install.packages("jsonlite")
install.packages("DT")
install.packages("ggplot2")
install.packages("scales")

4. API 키 저장 (권장)
---------------------
매번 키를 입력하지 않으려면 .Renviron 파일에 저장해 두세요.

a) R 콘솔에서 실행:
   file.edit("~/.Renviron")

b) 아래 두 줄을 추가하고 저장:
   KIWOOM_APP_KEY=발급받은앱키
   KIWOOM_SECRET_KEY=발급받은시크릿키

c) R을 재시작하면 앱 실행 시 키가 자동으로 입력됩니다.

* 주의: .Renviron 파일이나 키를 절대 다른 사람과 공유하거나
  깃허브 등에 업로드하지 마세요.

5. 실행 방법
------------
a) R 또는 RStudio를 실행합니다.
b) 작업 디렉토리를 이 저장소 폴더로 이동합니다:
   setwd("저장소 폴더 경로")
c) 다음 명령어로 앱을 실행합니다:
   shiny::runApp("kiwoom_dashboard")
d) 브라우저가 열리면:
   - 접속 환경 선택 (실전투자 / 모의투자)
   - App Key, Secret Key 입력 (환경변수 저장 시 자동 입력)
   - [보유내역 조회] 버튼 클릭

6. 화면 설명
------------
a) 요약 카드:
   - 추정예탁자산 : 예수금 포함 계좌 전체 추정 자산
   - 총매입금액 / 총평가금액 / 총평가손익 / 총수익률
   - 이익은 빨간색, 손실은 파란색으로 표시됩니다.

b) 보유종목 상세 표:
   - 종목코드, 종목명, 보유수량, 매입가, 현재가, 매입금액,
     평가금액, 평가손익, 수익률, 비중(%)
   - [CSV 저장] 버튼으로 엑셀에서 열 수 있는 파일로 저장 가능

c) 보유비중 그래프:
   - 평가금액 기준 상위 15개 종목 + 기타

d) 종목별 평가손익 그래프:
   - 이익 상위 10개 + 손실 상위 10개 (20종목 이하면 전체 표시)

e) 자동 새로고침:
   - 체크하면 60초마다 자동으로 재조회합니다.

7. 문제 해결
------------
a) "토큰 발급 실패" 오류:
   - App Key / Secret Key가 정확한지 확인
   - 실전투자 키로 모의투자에 접속(또는 그 반대)하지 않았는지 확인
   - 키움 REST API 서비스 신청이 완료되었는지 확인

b) "잔고 조회 실패" 오류:
   - 오류 메시지에 표시되는 키움 응답 내용을 확인
   - 장 시작 전/휴장일에는 일부 값이 0으로 나올 수 있습니다.

c) 보유종목이 비어 있는 경우:
   - 해당 계좌에 보유종목이 없는 정상 상태일 수 있습니다.
   - 모의투자 환경이면 모의투자 계좌 기준으로 조회됩니다.

d) 한글이 깨지는 경우:
   - RStudio 메뉴 Tools > Global Options > Code > Saving 에서
     Default text encoding을 UTF-8로 설정 후 파일을 다시 여세요.

8. 추가 정보
------------
- 보유종목이 많아 응답이 나뉘는 경우(연속조회)에도 자동으로
  전체 종목을 이어서 수집합니다.
- 접근토큰은 만료 시각 전까지 재사용하므로 불필요한 재발급이 없습니다.
- 그래프 색상이나 표시 종목 수는 kiwoom_dashboard/app.R 에서 수정 가능합니다.

문의사항이 있으시면 스크립트 내 주석을 참고하세요.
